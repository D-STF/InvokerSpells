# Invoker Spells

Аркадная игра на Python (Pygame-ce) для тренировки скорости и памяти при комбинировании заклинаний Инвокера. 

## Особенности игры
* **Два игровых режима:**
* 
  * **DotA 1 (27 заклинаний):** классический хардкорный режим, где порядок сфер (`Q`, `W`, `E`) имеет значение. https://photobooth.cdn.sports.ru/preset/message/0/66/f91c78b9f48eda58ba781e6d0f8e2.jpeg?f=webp&q=90&s=2x&w=730****
*   
  * **Dota 2 (10 заклинаний):** современный режим, где порядок нажатия сфер не важен. https://avatars.mds.yandex.net/i?id=193d9a0a67ede4f42397af87842dd628_l-5473533-images-thumbs&n=13#
*
* **Встроенный интерактивный гайд:** справочник всех комбинаций прямо на экране с подсветкой текущего загаданного заклинания.
*
* **Адаптивный интерфейс:** окно игры свободно масштабируется под любое разрешение экрана.
*
* **Таймер и счетчик очков:** раунд длится 60 секунд, исключено выпадение одного и того же заклинания дважды подряд.

## Управление
* `Q` — сфера **Quas**
* `W` — сфера **Wex**
* `E` — сфера **Exort**
* `R` — создать заклинание (**Invoke**)
* `Tab` —  переключить режим (DotA 1 / Dota 2)
* `Space` — начать заново после окончания времени
* `Esc` — вернуться в главное меню

## Установка и запуск

1. Клонируйте репозиторий или скачайте архив с проектом:
   ```bash
   git clone <https://github.com/D-STF/InvokerSpells>
   cd invokerspells
   ```

2. Установите необходимую библиотеку:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите игру:
   ```bash
   python main.py
   ```

## Структура проекта
* `main.py` — точка входа, игровой цикл и обработка событий.
* `logic.py` — игровая логика, очередь сфер, подсчет очков и таймер (`InvokerSpells`).
* `spells.py` — словари рецептов для первой (27) и второй (10) Доты.
* `graphics.py` — адаптивная отрисовка интерфейса, меню и гайда (`GameRenderer`).
* `assets/icons/` — иконки сфер и заклинаний из Warcraft 3 и Dota 2.
